## 🇨🇳 中文

把简报、剧本或选中的素材做成 LibTV 图片与视频，也能续作已有的 LibTV 项目，并把验证过的媒体回传画布。流程先明确交付：类型、主体与风格、参考素材、目标项目、模型偏好、画幅、清晰度、产出数量与预算；视频还要确认时长和是否需要声音。随后验证账户访问并告知剩余积分，避免跑到一半才发现额度不够；生成前再做兼容性检查，尤其是视频对模型与参数的要求。选中的参考素材会上传到你的 LibTV 账户，且只上传相关素材。只有用户明确选择 LibTV 时才走这套流程，建立连接不等于授权付费生成。

### ✨ 能做什么

- 简报 / 剧本 / 选中素材 → LibTV 图片与视频
- 生成前验证账户访问并告知剩余积分
- 视频开跑前检查模型与参数兼容性
- 明确模型偏好或自动推荐，不编造模型菜单
- 只上传相关参考素材，验证后的媒体回传画布
- 续作已有 LibTV 项目，保持同一项目上下文

## 🇬🇧 English

Turns a brief, script or selected assets into LibTV images and video, continues an existing LibTV project, and returns verified media to the canvas. It pins down the deliverable first — type, subject and style, references, target project, model preference, aspect ratio, resolution, count and budget, plus duration and audio for video — then verifies account access and reports the remaining credits before generating, so you never run dry mid-batch. Video runs get a compatibility check against model and parameter requirements up front. Only the references you selected are uploaded to your LibTV account. The flow applies when LibTV is explicitly chosen, and connecting an account is never treated as approval to spend.

### ✨ What it does

- Brief, script or selected assets in; LibTV images and video out
- Account access verified and remaining credits reported before generating
- Model and parameter compatibility checked before any video run
- Model preference or auto-recommend, with no invented model menus
- Only relevant references uploaded; verified media returned to the canvas
- Continues existing LibTV projects in the same project context
